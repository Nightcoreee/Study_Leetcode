# 🚀 LeetCode Grind: Blind 75 + Hello Interview + SQL 50

Repo ghi lại quá trình luyện giải thuật và SQL để chuẩn bị phỏng vấn backend. Mỗi bài đều có lời giải bằng **JavaScript** (và **SQL** cho phần database), kèm ghi chú cách nghĩ, độ phức tạp và các hướng giải khác.

## 📚 Nội dung

| Danh sách | Mô tả | Ngôn ngữ |
|---|---|---|
| [Blind 75](https://leetcode.com/problem-list/oizxjoit/) | 75 bài kinh điển bao phủ các dạng cấu trúc dữ liệu và giải thuật phổ biến | JavaScript |
| [Hello Interview](https://www.hellointerview.com/learn/code/two-pointers/overview) | Tuyển tập bài theo từng pattern từ Hello Interview | JavaScript |
| [SQL 50](https://leetcode.com/studyplan/top-sql-50/) | 50 bài SQL của LeetCode: SELECT, JOIN, GROUP BY, subquery, window function | SQL (PostgreSQL) |

## 🎯 Mục tiêu

- Nắm vững các pattern thường gặp: two pointers, sliding window, binary search, DFS/BFS, dynamic programming, heap, graph...
- Với mỗi bài, thử **ít nhất 2 cách giải** (brute force → tối ưu) và so sánh độ phức tạp.
- Thành thạo SQL cho các câu truy vấn thực tế: JOIN nhiều bảng, aggregate, window function, CTE.
